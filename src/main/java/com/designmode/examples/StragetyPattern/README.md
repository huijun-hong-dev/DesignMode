# 场景引入
你刚学完简单工厂，想想这个场景——
支付系统里，不同支付方式的选择逻辑用工厂解决了。但现在来个新需求：
不同支付方式，计算手续费的规则不一样。支付宝收 0.6%，微信收 0.5%，银行卡收 1% + 固定 2 元。

#  Strategy Pattern
1. 什么是策略模式?
工厂模式解决的是"创建哪个对象"
策略模式解决的是"怎么做某件事"（算法/行为可以互换）

2. 核心思想
定义一系列算法，把它们封装起来，让它们可以互相替换，客户端不关心用的是哪个。
一句话：行为的多态切换。

面向对象的编程并不是类越多越好，类的分类是未来分类，但分类基础是抽象，具有相同的属性和功能的对象的抽象集合才是类
